Here's a clean Go implementation of an in-memory event bus with worker concurrency, followed by a comparison table of popular message brokers for scalability.

In-memory event bus (Go)

This implementation provides a simple, production-ready event bus with:

  • Concurrent event processing using worker pools
  • Context support for cancellation
  • Graceful shutdown
  • Type-safe event handling
go 
package eventbus

import (
    "context"
    "fmt"
    "sync"
)

type Event struct {
    Type    string
    Payload any
}

type EventBus struct {
    subscribers map[string][]chan Event
    mu          sync.RWMutex
    workers     int
    closed      bool
}
